unitreerobotics/unitree_model

RobotiqueDocumentationActif

Problème résolu

Fournir des modèles de robots 3D (format URDF) pour les robots quadrupèdes et humanoïdes Unitree pour permettre la simulation dans les moteurs physiques et les frameworks de robotique sans rétro-ingénierie de fichiers CAO propriétaires.

Comment ça marche

Le référentiel contient des fichiers URDF (Unified Robot Description Format) décrivant les chaînes cinématiques des robots Unitree, les géométries des liaisons et les paramètres des articulations. Les modèles sont conçus pour l'importation dans Isaac Sim (Nvidia Omniverse) et autres simulateurs compatibles URDF (Gazebo, PyBullet). Le README documente le flux de conversion via l'importateur URDF d'Isaac Sim avec configuration spécifique des articulations (rigidité, commande basée sur la force) et paramètres de collision. Aucun code personnalisé ni dépendances au-delà des outils URDF standard ; principalement un référentiel de données.

Spécificité chinoise

Hébergé sur Gitee/GitHub par unitreerobotics (Unitree Robotics, un fabricant chinois de robots quadrupèdes) ; aucune spécificité chinoise particulière au-delà de l'auteur. Aucune intégration avec les plateformes cloud chinoises, les fournisseurs de puces ou les normes citées.

Équivalent occidental

Modèles URDF Boston Dynamics Spot (propriétaires), ANYmal URDF (ANYbotics), référentiels de modèles Clearpath Robotics
