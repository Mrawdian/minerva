## unitreerobotics/Python_unitree_demos
**Type :** Application
**Domaine :** Robotique
**Score de pertinence :** 60/100
**Problème résolu :** Fournir des routines d'exemple Python pour intégrer les robots quadrupèdes Unitree avec les systèmes SLAM (Simultaneous Localization and Mapping) dans les applications industrielles, permettant aux développeurs de prototyper rapidement les pipelines de perception et de navigation sur le matériel Unitree.
**Comment ça marche :** Le projet se compose de scripts de démonstration Python ciblant les plateformes de robots Unitree (probablement les quadrupèdes Unitree Go1/Go2). Il exploite le SDK Unitree et intègre les flux de travail SLAM, bien que les dépendances exactes, la bibliothèque SLAM (par exemple ORB-SLAM2, Cartographer) et les protocoles de communication (ROS, API Unitree propriétaires) ne puissent être confirmés sans accès au code réel. Les exemples sont destinés à accélérer le développement d'applications de robotique industrielle sur le matériel Unitree.
**Spécificité chinoise :** Unitree Robotics est une entreprise chinoise spécialisée dans la conception et la fabrication de robots quadrupèdes. Le projet soutient directement les plateformes de robots commerciaux d'Unitree (séries Go1, Go2, B1, H1), qui sont fabriquées et vendues principalement sur le marché chinois, bien que de plus en plus distribuées à l'international.
**Équivalent occidental :** Boston Dynamics Spot SDK (exemples Python), exemples d'intégration ROS ANYmal, tutoriels SLAM Clearpath Robotics Jackal/Husky
**Maturité :** Actif (mis à jour 2026-07)
**Langue :** Anglais
**GitHub :** https://github.com/unitreerobotics/Python_unitree_demos
