## alibaba/collabobot
**Type :** Tool
**Domaine :** Edge AI
**Score de pertinence :** 57/100
**Problème résolu :** Automatise les tâches répétitives de gestion des dépôts GitHub open-source (rapports hebdomadaires, étiquetage des issues, traduction automatique).
**Comment ça marche :** Collabobot est une application GitHub construite sur le framework Probot, écrite en TypeScript. Elle s'installe comme webhook sur les dépôts et reçoit les événements GitHub pour exécuter des actions automatisées. L'architecture repose sur Node.js avec configuration via fichier globalConfig.js contenant les identifiants d'authentification (App ID, secret webhook, certificat PEM) nécessaires pour l'authentification auprès de l'API GitHub.
**Spécificité chinoise :** Alibaba, géant technologique chinois, propose cet outil pour faciliter la collaboration sur les projets open-source hébergés sur GitHub. La fonctionnalité de traduction automatique des issues répond aux besoins des contributeurs chinois dans un écosystème dominé par l'anglais.
**Équivalent occidental :** Probot (framework parent), GitHub Actions, Dependabot, Renovate
**Maturité :** Expérimental (mis à jour 2024-10)
**Langue :** EN
**Gitee :** https://gitee.com/alibaba/collabobot
