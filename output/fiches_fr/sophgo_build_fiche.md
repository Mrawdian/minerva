## sophgo/build
**Type :** Board Support Package
**Domaine :** Embarqué
**Score de pertinence :** 64/100
**Problème résolu :** Fournir la configuration de compilation et l'infrastructure de compilation pour la série SoC CV18xx (processeurs CVITEK/SOPHGO). Permet aux développeurs de compiler le firmware, les bootloaders et les images du noyau ciblant cette plateforme embarquée basée sur ARM.
**Comment ça marche :** Référentiel de configuration du système de compilation pour les SoC CV18xx, contenant probablement les règles Makefile, les paramètres du compilateur croisé et les scripts de compilation. Le langage principal est l'anglais ; les dépendances et les versions exactes de la chaîne d'outils doivent être confirmées. Cible les systèmes embarqués basés sur ARM ; l'intégration avec U-Boot, le noyau Linux et les composants RTOS est typique pour de tels systèmes de compilation BSP.
**Spécificité chinoise :** SOPHGO (anciennement CVITEK) est une entreprise chinoise de semi-conducteurs sans usine spécialisée dans l'IA en périphérie et les SoC de traitement vidéo. CV18xx est leur ligne de processeurs embarqués grand public utilisée dans les applications de surveillance, de robotique et d'IoT chez les fabricants chinois.
**Équivalent occidental :** Buildroot, Yocto Project (Linux Foundation), frameworks Linaro BSP
**Maturité :** Actif (★ 4, 21 forks, mis à jour 2026-07)
**Langue :** Anglais
