## bouffalolab/bl_iot_sdk-customer_app
**Type :** Application
**Domaine :** Edge AI
**Score de pertinence :** 57/100
**Problème résolu :** Fournir un sous-module d'application client pour le BL IoT SDK, permettant aux développeurs de construire des applications IoT sur les puces Bouffalo Lab sans implémenter la fonctionnalité SDK principale à partir de zéro.
**Comment ça marche :** Ceci est un référentiel de sous-module au sein de l'écosystème bl_iot_sdk_tiny, conçu pour contenir le code d'application et les exemples destinés aux clients. Il s'intègre avec le framework parent bl_iot_sdk_tiny, qui cible les SoC RISC-V et ARM de Bouffalo Lab. Le module contient probablement des modèles d'application, du code d'exemple et des points d'intégration pour les protocoles IoT et les pilotes périphériques fournis par le SDK parent.
**Spécificité chinoise :** Bouffalo Lab est une entreprise chinoise de semi-conducteurs spécialisée dans les SoC sans fil à faible consommation (BL602, BL808, etc.). Ce référentiel fait partie de leur écosystème SDK IoT officiel, directement lié à leur portefeuille de puces RISC-V et ARM et au marché plus large du matériel IoT chinois.
**Équivalent occidental :** Exemples ESP-IDF (Espressif), exemples d'applications Zephyr (Linux Foundation), modèles de projet STM32CubeMX (STMicroelectronics)
**Maturité :** Actif (★ 1, 1 forks, mis à jour 2026-06)
**Langue :** Anglais
