## kendryte/k230_rtos_docs
**Type :** Documentation
**Domaine :** Embarqué
**Score de pertinence :** 51/100
**Problème résolu :** Fournir une documentation et des matériaux de référence pour la plateforme RTOS Kendryte K230, permettant aux développeurs de comprendre l'architecture du système d'exploitation temps réel, les API et les modèles d'intégration spécifiques au SoC K230.
**Comment ça marche :** Ceci est un référentiel de documentation pour le K230 RTOS, un système d'exploitation temps réel ciblant le SoC RISC-V dual-core K230 de Kendryte. Le projet contient des spécifications techniques, des références d'API et des guides d'intégration rédigés en anglais. Il sert de matériel de référence principal pour les développeurs travaillant avec les composants du firmware K230 et du noyau.
**Spécificité chinoise :** Kendryte est une entreprise chinoise de semi-conducteurs sans usine spécialisée dans les SoC RISC-V ; le K230 est leur processeur dual-core phare. Cette documentation soutient directement l'écosystème RTOS propriétaire de Kendryte et la plateforme matérielle K230, représentant une partie essentielle de leur offre de systèmes embarqués sur le marché chinois.
