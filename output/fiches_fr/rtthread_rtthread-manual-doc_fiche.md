## rtthread/rtthread-manual-doc
**Type :** Documentation
**Domaine :** Embarqué
**Score de pertinence :** 43/100
**Problème résolu :** Fournir une documentation complète et collaborative pour le noyau temps réel RT-Thread, couvrant la programmation, l'architecture et l'utilisation du système d'exploitation embarqué.
**Comment ça marche :** Le projet utilise Markdown pour rédiger une documentation technique structurée en chapitres couvrant la gestion des threads, la synchronisation, la gestion mémoire et les pilotes. La documentation est versionnée sur GitHub avec intégration continue via Travis-CI pour générer automatiquement des fichiers PDF. Un système collaboratif permet aux contributeurs de proposer des modifications via pull requests, avec révision et fusion dans la version officielle.
**Spécificité chinoise :** RT-Thread est un RTOS développé en Chine largement adopté dans l'écosystème IoT et robotique chinois (Huawei, Alibaba, Baidu). Cette documentation soutient l'adoption du système dans les projets embarqués chinois et les universités du pays.
**Équivalent occidental :** Documentation officielle de FreeRTOS, Zephyr Project documentation, ou RIOT OS documentation
**Maturité :** Expérimental (★ 40, 24 forks)
**Langue :** Bilingue CN-EN
