## rtthread/rtthread-manual-doc
**Type:** Documentation
**Domain:** Embedded
**Relevance score:** 43/100
**Problem solved:** Provide comprehensive and collaborative documentation for the RT-Thread real-time kernel, covering programming, architecture, and embedded operating system usage.
**How it works:** The project uses Markdown to write structured technical documentation organized in chapters covering thread management, synchronization, memory management, and drivers. The documentation is versioned on GitHub with continuous integration via Travis-CI to automatically generate PDF files. A collaborative system allows contributors to propose modifications via pull requests, with review and merging into the official version.
**Chinese specificity:** RT-Thread is an RTOS developed in China widely adopted in the Chinese IoT and robotics ecosystem (Huawei, Alibaba, Baidu). This documentation supports the adoption of the system in Chinese embedded projects and universities in the country.
**Western equivalent:** FreeRTOS official documentation, Zephyr Project documentation, or RIOT OS documentation
