## bouffalolab/bl_iot_sdk
**Type:** Board Support Package
**Domain:** Embedded
**Relevance score:** 80/100
**Problem solved:** Provide a unified SDK for Bouffalo Lab's RISC-V Wi-Fi/BLE combo (BL602) and Zigbee/BLE (BL70X) chipsets, replacing fragmented vendor documentation and enabling rapid IoT device development on these SoCs.
**How it works:** The SDK includes HAL drivers, FreeRTOS kernel integration, Wi-Fi/BLE/Zigbee protocol stacks, and peripheral drivers (UART, SPI, GPIO, ADC, PWM) for BL602 and BL70X RISC-V cores. Written in C with bilingual (Chinese/English) documentation. Depends on GCC RISC-V toolchain and FreeRTOS. Supports both bare-metal and RTOS-based application development with example projects for common IoT use cases.
**Chinese specificity:** Bouffalo Lab is a Chinese semiconductor vendor specializing in low-power RISC-V IoT SoCs. The BL602 and BL70X are proprietary Bouffalo designs; this SDK is the official development environment for these chipsets within the Chinese IoT ecosystem.
**Western equivalent:** Espressif ESP-IDF (ESP32), Nordic nRF5 SDK, Silicon Labs Gecko SDK
