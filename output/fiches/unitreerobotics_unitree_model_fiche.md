## unitreerobotics/unitree_model
**Type:** Documentation
**Domain:** Robotics
**Relevance score:** 69/100
**Problem solved:** Provide 3D robot models (URDF format) for Unitree quadruped and humanoid robots to enable simulation in physics engines and robotics frameworks without reverse-engineering proprietary CAD files.
**How it works:** Repository contains URDF (Unified Robot Description Format) files describing Unitree robot kinematic chains, link geometries, and joint parameters. Models are designed for import into Isaac Sim (Nvidia Omniverse) and other URDF-compatible simulators (Gazebo, PyBullet). The README documents conversion workflow via Isaac Sim's URDF importer with specific joint configuration (stiffness, force-based drive) and collision settings. No custom code or dependencies beyond standard URDF tooling; primarily a data repository.
**Chinese specificity:** Hosted on Gitee/GitHub by unitreerobotics (Unitree Robotics, a Chinese quadruped robot manufacturer); no particular Chinese specificity beyond the author. No integration with Chinese cloud platforms, chipset vendors, or standards cited.
**Western equivalent:** Boston Dynamics Spot URDF models (proprietary), ANYmal URDF (ANYbotics), Clearpath Robotics model repositories
