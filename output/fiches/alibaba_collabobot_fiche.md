## alibaba/collabobot
**Type:** Tool
**Domain:** Edge AI
**Relevance score:** 57/100
**Problem solved:** Automates repetitive management tasks for open-source GitHub repositories (weekly reports, issue labeling, automatic translation).
**How it works:** Collabobot is a GitHub application built on the Probot framework, written in TypeScript. It installs as a webhook on repositories and receives GitHub events to execute automated actions. The architecture relies on Node.js with configuration via globalConfig.js file containing authentication identifiers (App ID, webhook secret, PEM certificate) necessary for authentication with the GitHub API.
**Chinese specificity:** Alibaba, Chinese technology giant, offers this tool to facilitate collaboration on open-source projects hosted on GitHub. The automatic issue translation feature addresses the needs of Chinese contributors in an English-dominated ecosystem.
**Western equivalent:** Probot (parent framework), GitHub Actions, Dependabot, Renovate
**Maturity:** Experimental (updated 2024-10)
**Language:** EN
**Gitee:** https://gitee.com/alibaba/collabobot
