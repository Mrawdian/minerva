## unitreerobotics/Qmini
**Type:** Application
**Domain:** Robotics
**Relevance score:** 72/100
**Problem solved:** Provide a fully open-source, 3D-printable bipedal robot platform with documented hardware (BOM, STEP files, electrical schematics), software stack (URDF, ROS integration via RoboTamer4Qmini), and assembly procedures to lower the barrier to entry for robotics hobbyists, educators, and researchers.
**How it works:** Qmini is a bipedal robot built around 11 Unitree 8010 servo motors (10 for locomotion, 1 for expansion), controlled via Raspberry Pi 4 Model B as the reference compute platform. The software stack includes a URDF model for ROS/Gazebo simulation and the RoboTamer4Qmini framework (hosted separately on GitHub) for motion control and gait algorithms. All mechanical components are 3D-printable; assembly requires standard tools and takes 3–5 hours. The project provides STEP files, BOM, electrical block diagrams, and DIY instructions in PDF format.
**Chinese specificity:** Hosted on Gitee/GitHub by unitreerobotics; no particular Chinese specificity beyond the author. Unitree Robotics is a Chinese company known for commercial quadruped platforms, but Qmini uses standard off-the-shelf components (Raspberry Pi, generic 3D printing materials) and does not depend on Chinese chipset vendors or proprietary ecosystems.
