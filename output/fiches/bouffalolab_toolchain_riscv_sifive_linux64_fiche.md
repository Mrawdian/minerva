## bouffalolab/toolchain_riscv_sifive_linux64
**Type:** Tool
**Domain:** Embedded
**Relevance score:** 32/100
**Problem solved:** Provide a RISC-V GCC toolchain targeting 64-bit Linux on SiFive platforms, enabling cross-compilation for RISC-V systems without reliance on SiFive's proprietary build infrastructure.
**How it works:** This is a pre-built or source-based GCC toolchain distribution for RISC-V ISA targeting Linux userspace on 64-bit systems. It includes binutils, GCC, and likely glibc or musl for the C library. The toolchain runs on x86_64 Linux hosts and produces RISC-V ELF binaries. No specific runtime or kernel components are bundled; it is a cross-compilation toolkit only.
**Chinese specificity:** Hosted on Gitee by Bouffalo Lab, a subsidiary of Nanjing Xiaoxin Semiconductor focused on RISC-V and wireless SoCs. However, this particular repository is a generic RISC-V/SiFive toolchain distribution with no Bouffalo-specific chipset integration or Chinese standard compliance evident.
**Western equivalent:** SiFive Freedom Tools (official SiFive GCC distribution), RISC-V GNU Toolchain (RISC-V International upstream)
**Maturity:** Experimental (updated 2025-08)
**Language:** English
