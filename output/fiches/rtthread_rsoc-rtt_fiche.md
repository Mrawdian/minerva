## rtthread/rsoc-rtt
**Type:** Documentation
**Domain:** Embedded
**Relevance score:** 75/100
**Problem solved:** Organize and centralize pedagogical notes and practical work of trainees in the RT-Thread summer program across different embedded hardware platforms.
**How it works:** The repository functions as a structured educational content management system organized by cohort (6 groups), hardware platform (STM32H750, RA8D1, PSoC62, MCXA156, K230, GD32F527I) and student. Each trainee maintains two parallel directory structures: a notes section covering RT-Thread RTOS kernel and driver aspects, and a practical work section with daily exercises. The structure enables progressive learning tracking over a defined duration (minimum 5 days per exercise).
**Chinese specificity:** Direct integration with the RT-Thread ecosystem (major Chinese real-time RTOS), use of GD32 microcontrollers (Gigadevice, Chinese manufacturer) and CanMV-K230 (Chinese embedded AI platform). Summer training program typical of Chinese embedded systems talent development initiatives.
**Western equivalent:** No known direct equivalent - combines aspects of educational repository (such as GitHub courses) with formalized internship program structure
**Maturity:** Experimental (★ 1, 66 forks, updated 2025-08)
**Language:** Bilingual CN-EN
