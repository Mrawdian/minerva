Problem solved
A scalable real-time OS that runs on resource-constrained MCUs (Cortex-M0, 3 KB Flash) yet scales up to Cortex-A / multicore IoT devices, unifying kernel, BSP, drivers and a modular component ecosystem.
How it works
A monolithic C kernel (threads, scheduler, IPC, timers) with a layered libcpu/BSP porting layer and a components layer (VFS, FinSH CLI, network stacks). A package manager offers 450+ modules; GCC/Keil/IAR toolchains.
Chinese specificity
Founded 2006; the largest home-grown Chinese RTOS community, widely designed into domestic industrial and IoT products.
Western equivalent ← the bridge a directory never gives you
FreeRTOS / Zephyr — closest to Zephyr for its component ecosystem and package manager, but with a larger Chinese-industrial install base.
