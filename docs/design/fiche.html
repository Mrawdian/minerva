sophgo/tpu-mlir

Edge AI Compiler / Toolchain Active

Problem solved

Compile and quantize trained neural networks into deployable binaries for Sophgo's TPU accelerators, without hand-writing kernels for each model.

How it works

An MLIR-based compiler stack: it imports ONNX / Caffe / TFLite graphs, lowers them through a dedicated TPU dialect, applies INT8 and BF16 quantization with a calibration table, and emits a bmodel consumed by the on-device runtime. Ships a Python toolchain and a model-zoo of validated conversions.

Chinese specificity

Tightly coupled to Sophgo's domestic BM1684X / CV18xx silicon — a home-grown alternative to the NVIDIA CUDA / TensorRT path, developed under export-control pressure on high-end accelerators. Documentation is bilingual CN/EN.

Western equivalent

Apache TVM plus a vendor toolchain (in the spirit of TensorRT / OpenVINO), but targeting Sophgo TPUs instead of NVIDIA / Intel silicon.
